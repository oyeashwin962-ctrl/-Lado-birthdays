# Lado Birthday Website

Personalized static website based on the supplied Interactive Birthday Wish project.

## Run locally
Open `index.html` in a modern browser, or serve this folder with any static web server. For best testing, use a local server rather than `file://`.

## Deploy to Vercel
Import the folder/repository into Vercel as a static site. No build command is required; the project root is this folder and the output directory is `.`.

## Included
- IST countdown to 27 November 2026, 00:00
- November 2026 birthday calendar shown after countdown completes
- Six user-provided photos in `assets/photos/`
- Marathi birthday poem and personalized love letter
- Song link for “Nawari Distes G” (opens YouTube search; audio file was not supplied)

## Notes
The site links to YouTube search for the requested song. It does not bundle copyrighted music. The browser will only play audio after the user initiates playback on the linked platform.


Audio: assets/nawari-distes-g.m4a is the user-provided song. Use the Play/Pause button; browsers block autoplay until a user gesture. Keep the assets folder alongside index.html.
